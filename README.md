An original GTA 6 meme, drawn programmatically with Python/PIL: a player who waited 13 years for GTA VI takes a sick day for launch day, while the make.fun ghost mascot at the next desk has already entered three bounties and earned real money. Posted on X at https://x.com/nkdc0223/status/2123628741444383069 — POST.json names the post, and main.ts validates the post URL, the post text (bounty link and play code) and the meme image, then writes the entry dossier to the output directory.

## Run it

```sh
node main.ts
```
